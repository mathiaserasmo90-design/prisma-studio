Política de Privacidad

Última actualización: julio de 2026

description Ver documento completo en Google Docs

En Prisma Studio valoramos la privacidad de nuestros usuarios. Esta política describe cómo manejamos tu información personal y técnica al usar nuestros juegos, incluido Prisma Pop. Al usar nuestras aplicaciones, aceptas los términos descritos aquí.

dataset

1. Información que recopilamos

Recopilamos ciertos datos automáticamente para asegurar el funcionamiento óptimo de nuestros juegos:

  • Datos de uso: tiempo de juego, niveles alcanzados y estadísticas de rendimiento.
  • Identificadores de dispositivo: dirección IP, ID de publicidad (como IDFA o GAID) y modelo del dispositivo.
  • Información técnica: versión del sistema operativo, resolución de pantalla y datos de fallos (crash logs).
psychology

2. Cómo utilizamos la información

Mejora del juego

Analizamos patrones de juego para ajustar la dificultad, corregir errores técnicos y diseñar nuevas funciones.

Análisis y estabilidad

Usamos datos agregados para entender el uso general del juego y detectar errores para corregirlos.

share

3. Divulgación de datos

No vendemos tus datos personales a terceros. Podemos usar proveedores de servicios externos para el funcionamiento del juego, por ejemplo:

Google Play Services Firebase Crashlytics

Cada uno de estos proveedores tiene su propia política de privacidad que regula cómo manejan los datos que reciben a través de nuestras aplicaciones.

verified_user

4. Seguridad y derechos del usuario

Implementamos medidas de seguridad técnicas y organizativas para proteger tus datos contra acceso no autorizado, alteración o pérdida.
